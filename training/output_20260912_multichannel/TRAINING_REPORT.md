# 五通道压力障碍物识别模型阶段测试报告

日期：2026年9月12日

## 一、结论

本次使用5路压力传感器数据完成了第一版障碍物识别模型训练。

模型在留出的测试数据上，实验级准确率为76.54%，其中障碍物检出率为72.22%，无障碍识别率为80.00%。结果表明，多通道压力数据具备一定辨识能力，当前方案可以进入板端联调和后续数据扩充阶段。

现阶段模型仍存在9次误报和10次漏检，不建议直接作为最终控制依据。主要问题是不同采集批次之间存在波形变化，说明模型对环境、安装状态和传感器漂移仍较敏感。

## 二、数据情况

本次共使用388次有效实验。训练、验证和测试均按完整采集批次划分，同一批次的数据不会同时出现在训练集和测试集中。

| 数据用途 | 无障碍 | 有障碍 | 合计 |
| --- | ---: | ---: | ---: |
| 训练 | 70 | 156 | 226 |
| 验证 | 56 | 25 | 81 |
| 测试 | 45 | 36 | 81 |
| 合计 | 171 | 217 | 388 |

空文件、雷达空数据以及传感器有效率不足的实验未纳入训练。其中，`20260912_145548_001.csv`的大部分实验未达到5路传感器有效率要求，因此被排除。

## 三、测试结果

| 指标 | 结果 |
| --- | ---: |
| 实验级准确率 | 76.54% |
| 障碍物检出率 | 72.22% |
| 无障碍识别率 | 80.00% |
| F1值 | 73.24% |
| 误报 | 9次 |
| 漏检 | 10次 |

验证数据上的结果明显高于测试数据，说明模型能够学习当前数据中的特征，但跨批次稳定性还不够。后续评价应以新增批次的测试结果为准，不以训练集或验证集结果作为最终准确率。

## 四、模型配置

模型同时读取5路压力信号，每次使用最近1秒的数据进行判断。采样率为200 Hz，输入长度为200点，判断阈值为0.87。

模型规模为6865个可训练参数，计算量较小，适合转换为昇腾OM模型后部署到Atlas 200I DK A2。数据标准化和差分处理已经包含在模型内部，板端只需按顺序输入5路原始压力值。

## 五、下一阶段工作

1. 将当前模型部署到Atlas，验证连续运行速度和实时判断结果。
2. 对9次误报和10次漏检逐一复核，确认是环境变化、传感器异常还是波形本身重叠。
3. 按相同设备状态继续增加独立采集批次，并覆盖不同日期、风扇状态和轻微安装偏差。
4. 使用新采集且未参与训练的数据进行最终测试，重点统计漏检率、误报率和提前判断时间。

## 六、当前判断

项目已经验证了多通道压力信号用于障碍物识别的可行性，但当前准确率尚未达到稳定应用要求。下一步重点是改善跨批次一致性，并通过新增独立数据确认实际效果。
